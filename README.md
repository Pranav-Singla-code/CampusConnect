# CampusConnect

A simple college event listing and registration website built with HTML, CSS and JavaScript.

## Features
- Browse sample college events
- Search events by name, description or venue
- Filter events by category
- Register using a name and email address
- Prevent duplicate registrations for the same event and email
- Save registrations in browser local storage
- Responsive layout for mobile and desktop

## Run locally
1. Download or clone this project.
2. Open `index.html` in a browser.
3. No build tools or package installation are required.

## Important note
This is a front-end demo project. Event data is stored in `script.js`, and registrations are saved in the current browser using `localStorage`. There is no backend, shared database, real authentication or email delivery.
